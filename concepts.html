Key Browser Concepts

Understanding a few important technical concepts makes it easier to explain how browsers display websites, execute code, and protect users.

1. HTML

HyperText Markup Language (HTML) defines the structure and content of a webpage, including headings, paragraphs, images, links, and tables.

2. CSS

Cascading Style Sheets (CSS) control how webpage content looks, including its colors, fonts, spacing, and layout.

3. Document Object Model (DOM)

The DOM represents a webpage's HTML as a structured collection of objects. JavaScript can use it to access and modify page content.

4. Rendering Engine

A rendering engine processes webpage structure and styles to determine how content should appear on the screen. Blink, Gecko, and WebKit are examples.

5. JavaScript Engine

A JavaScript engine executes JavaScript code, allowing websites to respond to user actions and provide interactive features.

6. Sandboxing

Sandboxing restricts what website content can access. It helps prevent a webpage from freely interacting with sensitive parts of a user's device.

7. Browser Fingerprinting

Browser fingerprinting uses characteristics of a browser or device to help recognize users, sometimes without relying on cookies.
